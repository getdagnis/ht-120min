# Shared predicted fixture ratings

`fixture_predicted_rating_shares` is the source of truth for a manager's explicit share of one team's prediction in one arranged fixture. It has one row per fixture and participating club, with a distinct row ID so a pending refresh can update only the same share. Removing the row revokes public sharing. The row stores seven converted sector values, formation, tactic, tactic skill, optional Set Pieces skill, the linked Hattrick MatchID, and the last successful fetch time. It never stores lineup, player IDs, raw XML, or credentials.

The public tournament projection selects only the fields in `PUBLIC_FIXTURE_RATINGS_FIELDS` and attaches rows only when their MatchID and participating team still match the fixture. Browser fixture refresh uses the same explicit field list. Reads are public under RLS; writes use the server's service role after a signed app session, fixture and manager checks, and live CHPP confirmation of the exact club. Shares are visible to all visitors until removed, but the strip is shown only for upcoming arranged fixtures.

Share and Update fetch `matchorders` v3.1 with `actionType=view` for submitted positions and the taker, then `actionType=predictratings` for sector ratings and tactic skill. If there is a taker, `playerdetails` v3.2 adds the optional Set Pieces skill. The prediction request uses the saved match orders by omitting a lineup parameter. Sector values convert with `(raw + 3) / 4`. An unavailable optional player skill becomes `—`; a failed match-order request leaves any prior snapshot and timestamp intact. The clicked fixture refresh alone refreshes opted-in shares in the actionable round, after checking that the requester participates or manages the tournament. Page-open and timed fixture checks do not request match orders.
