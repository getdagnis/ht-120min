# Shared predicted fixture ratings

`fixture_predicted_rating_shares` is the source of truth for a manager's explicit share of one team's prediction in one arranged fixture. It has one row per fixture and participating club, with a distinct row ID so a pending refresh can update only the same share. Removing the row revokes sharing. The row stores seven converted sector values, formation, tactic, tactic skill, the optional coach modifier, optional Set Pieces skill, the linked Hattrick MatchID, and the last successful fetch time. It never stores lineup, player IDs, raw XML, or credentials.

The public tournament projection and browser fixture refresh read `fixture_predicted_rating_share_status`, a narrow view that exposes only fixture ID, team ID, and MatchID for valid upcoming shares. Other visitors see a notice for each sharing club, or nothing when neither has shared. The base table is not publicly readable. A private, uncached `GET /api/app?route=fixture-ratings&tournamentId=...` returns both clubs' snapshots only to a signed-in manager whose stored credentials and live CHPP team list confirm ownership of an exact participating club. The values disappear at kickoff. On localhost only, the signed-in site admin identified by the configured `FORGE_SUPERADMIN_HT_ID` may see all upcoming shared snapshots when that variable is set to `8777402`; this exception does not apply in production. Share, Update, and Remove still require exact club ownership. Writes use the server's service role after session, fixture, and manager checks.

Share and Update fetch `matchorders` v3.1 with `actionType=view` for submitted positions, the taker, and the coach modifier, then `actionType=predictratings` for sector ratings and tactic skill. Only the exact -10/+10 coach-modifier endpoints are labeled and colored as Defensive 100%/Offensive 100%; neutral and intermediate settings remain unmarked. If there is a taker, `playerdetails` v3.2 adds the optional Set Pieces skill. The prediction request uses the saved match orders by omitting a lineup parameter. Sector values convert with `(raw + 3) / 4`. An unavailable optional player skill becomes `—`; a failed match-order request leaves any prior snapshot and timestamp intact. The clicked fixture refresh alone refreshes opted-in shares in the actionable round, after checking that the requester participates or manages the tournament. Page-open and timed fixture checks do not request match orders.
