# Average 120 min scoring

`average120` is a separate persisted value in `tournaments.scoring_mode`. It uses the standard 120-minute ruleset and the existing match classifications. Raw achievement, tie-break point, minute, goal-difference, and goal totals remain in standings and season snapshots; each displayed/ranked average divides by the team's counted completed matches. Completed BYEs and unplayed fixtures do not count. A physical season slot owns substitute results, so current occupants inherit results from former occupants in both live standings and new `average120` history snapshots.

As in APPG-120, a team qualifies after playing at least half as many counted completed matches as the most active team, rounded up. Qualified teams rank above provisional teams. Within each group rank by unrounded 120-minute achievement percentage, then total achievements, average tie-break points, goal difference, goals, and minutes; preserve join order on a complete tie. At a maximum of two played matches the quota is one, so 2/2 ranks above 1/1, which ranks above 1/2. When the maximum is twelve the quota is six, so 9/12 ranks above a provisional 1/1. Teams with no counted results follow teams with results and display `—`. The visible `120m%` remains the raw percentage, and `120m/G` remains the achieved/played count. The public standings and forum export show provisional rows below a quota divider without placement. New season snapshots use this rule for champion and closest-finish records; stored earlier snapshots are not rewritten. Existing `120min`, `120m`, `points`, and `appg` profiles keep their algorithms and snapshot shape.

No database migration is required by the repository schema: `tournaments.scoring_mode` is unconstrained `TEXT`, and the public snapshot already carries it. The organizer chooses this mode through Create or Admin; no existing row is changed automatically. If the live database has an undocumented constraint, inspect it before selecting the mode there.
